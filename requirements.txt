# The shareable ROI card is a Jinja2 HTML template rendered server-side.

# WeasyPrint is the HTML renderer named by the feature spec. Note that it has
# emitted PDF ONLY since v53 -- `write_png` was removed -- so the card is

# endpoint therefore always returns a PNG; see that module for which path ran.
